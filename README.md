# 智汇银行 AI 智能体（AI Banking Agent）

> 2026 第八届 FinTechathon 深圳国际金融科技大赛・国内赛道・人工智能

## 一、项目简介

本项目构建了一个可通过自然语言交互的银行智能助手（AI Banking Agent）。用户用一句话表达金融意图，Agent 自主理解、规划并调用银行工具完成操作，全程在安全框架内执行，并对每一步操作留痕审计。

**核心理念**：AI 不是 "问答工具"，而是 "能动手办事的金融参与者"—— 但每一次动手都受权限约束、可追溯、可拦截。

## 三、核心技术设计

### 1. 多轮任务规划（ReAct 式 Agent）

基于 DeepSeek 大模型 + Function Calling，Agent 可自主完成多步规划。典型联动任务自动拆为 4 步：

查订阅 → 查理财产品 → 取消自动续费 → 申购货币基金。

### 2. 四级权限分级（对应赛题 "权限分级机制"）



| 级别 | 操作类型                  | 处理方式          |
| -- | --------------------- | ------------- |
| L0 | 只读查询（余额、账单、订阅列表）      | 直接放行          |
| L1 | 低风险写操作（取消订阅、调额度、加收款人） | 放行并记日志        |
| L2 | 资金操作（转账、申购）           | 需二次确认，≥1 万元拒绝 |
| L3 | 越权 / 未知操作             | 直接拒绝          |

**新增风控**：24 小时内新添加的收款人，单笔转账限额 500 元（防电信诈骗）。

### 3. 幻觉防护（对应赛题 "幻觉防护"）



* **系统提示强约束**：金额 / 余额必须来自工具返回，禁止编造；

* **数字溯源校验**：模型最终回复中出现的金额，会与本轮工具返回的数字集合比对，对不上则标注 "⚠️ 可疑数字"；

* 实测：对未查过的数字问题（如 "去年花了多少"），Agent 不会编造。

### 4. 提示注入防御（对应赛题 "注入防御"）



* 输入层关键词黑名单，拦截 "忽略以上指令" 等典型注入；

* 系统提示与用户指令分层，防止用户输入覆盖系统约束。

### 5. 多轮记忆

对话历史持久化存储，Agent 可记住用户姓名、上下文，支持连续对话。

### 6. 审计日志

每一次意图识别、闸门判定、工具调用、执行结果都写入数据库，可追溯、可回放。

## 五、技术栈



| 层        | 技术                                          |
| -------- | ------------------------------------------- |
| 大模型      | DeepSeek-V3（deepseek-chat，Function Calling） |
| Agent 编排 | 自研 ReAct 多轮循环                               |
| 数据库      | SQLite（账户、账单、订阅、交易流水、审计日志、对话历史）             |
| 后端       | Python + FastAPI（预留）                        |
| 前端       | Streamlit 可视化界面（聊天 + 实时审计日志面板）              |

## 六、如何运行



```

.\.venv\Scripts\Activate.ps1

# 2. 配置 .env（填入 DEEPSEEK_API_KEY）

# 3. 首次运行：初始化数据库（自动建表 + 灌入演示数据）
python db.py

# 4. 启动网页界面
streamlit run app.py

# 或命令行模式
python bank_agent.py
```
